# Cursor AI Handoff

Last Updated: 2026-09-05 03:30

## Current Objective
타이틀바 없는 640×290 창을 시작 애니메이션, 부스트 홈, 통합 설정의 compact UI로 구성한다.

- `src/index.mjs`는 CLI 해석과 실행 흐름만 담당하도록 축소했다.
- affinity 기능은 `src/affinity.mjs`, 메모리 기능은 `src/memory.mjs`로 분리했다.
- 구문 검사, `npm run self-test`, `npm run memory:status`가 통과했다.

## Architecture / Important Decisions
- affinity 모듈이 CPU 마스크 계산, 프로세스 탐색, 적용·복구, 상태 저장을 소유한다.
- 마비노기 적용은 `applyToGameProcesses`, 다른 프로그램 적용은 `applyToBackgroundProcesses`로 구분한다.
- memory 모듈이 NT 메모리 조회, standby 정리, 임계치와 타이머 상태를 소유한다.
- 진입점은 두 모듈의 생명주기와 종료 시 복구 순서만 조정한다.
- NVIDIA 프로필 조회는 Koffi로 `nvapi64.dll`의 DRS 함수 포인터를 호출한다.
- DRS 앱 탐색은 동명 실행 파일 오탐을 막기 위해 전체 경로를 먼저 사용한다.
- 공개 설정은 공식 `NvApiDriverSettings.h` ID와 공개 4인자 `DRS_GetSetting` ABI를 사용한다.
- 저지연 울트라는 비공개 CPL 상태, 드라이버 활성화, 최대 사전 렌더링 1을 모두 만족할 때만 판정한다.
- NVIDIA 수직 동기화가 응용 프로그램 제어이면 마비노기 HKCU `VerticalSync` 값을 읽어 구성 상태를 판정한다.
- NVIDIA 상태 조회는 읽기 전용이고 적용은 전용 명령에서만 수행한다.
- 적용 목표는 VSync 끄기, 400 FPS, 스레드 최적화 켜기, 최고 성능 선호, 저지연 울트라와 사전 렌더링 1이다.
- 패스트핑 대상은 연결된 IPv4 기본 경로 중 라우트 메트릭과 인터페이스 메트릭 합이 가장 낮은 어댑터다.
- 패스트핑은 `TcpAckFrequency=1`, `TCPNoDelay=1` 두 DWORD만 사용하며 `TcpDelAckTicks`는 변경하지 않는다.
- 조회는 일반 권한에서도 가능하고, 값이 다를 때만 관리자 권한으로 쓰고 즉시 다시 읽어 검증한다.
- 새 값을 쓴 경우에만 `Restart-NetAdapter`로 선택한 인터페이스를 자동 재시작한다.
- 이미 설정된 인터페이스는 기본 실행에서 재시작하지 않으며 `fast-ping:restart`로만 강제 재시작한다.
- 재시작 후 최대 15초 동안 어댑터가 `Up` 상태로 돌아오는지 검증한다.
- Electron 렌더러는 context isolation과 sandbox를 활성화하고 preload의 제한된 IPC만 노출한다.
- 앱은 기존 NVIDIA·네트워크 모듈을 직접 재사용하며 NVIDIA 모듈 구현은 웹앱 작업에서 수정하지 않았다.
- 네트워크 설정 적용은 승격된 Electron 앱에서 별도 보조 프로세스를 실행하고 임시 JSON으로 결과를 반환한다.
- TCP 자동 조정은 시스템 전역 `Internet` TCP 설정의 유효 수준이 `Normal`일 때만 최적화로 판정한다.
- 로컬 값보다 그룹 정책 값을 우선하며, 정책이 `Normal` 이외의 값을 강제하면 복구 실패로 표시한다.
- 복구는 `netsh interface tcp set global autotuninglevel=normal` 실행 후 PowerShell API로 재검증한다.
- TCP 자동 조정 적용도 승격된 앱의 별도 Electron 보조 프로세스에서 수행한다.
- 일반 앱 시작은 메인 ESM 평가를 끝낸 뒤 비동기로 `app.whenReady()`를 기다려 Electron 준비 이벤트와 교착하지 않는다.
- Vite `base`는 `"./"`로 유지해 빌드된 JS·CSS가 `dist/index.html` 기준으로 로드되게 한다.
- NIC RSS는 프로세서 그룹 0의 CPU 0~7로 제한하고 게임 CPU 8~15와 수신 처리를 분리한다.
- NIC RSS 적용 전 원본 설정을 LocalAppData에 보존하고 명시적 복원 명령에서만 되돌린다.
- 장치 IRQ affinity 레지스트리는 변경하지 않고 RSS steering만 제어한다.
- Electron Affinity 켜기는 승격된 앱의 관리자 토큰을 상속한 별도 helper로 실행한다.
- UI와 helper는 `%APPDATA%\nogirem\affinity`의 상태·제어 JSON으로 통신하고 상태 파일은 임시 파일 rename으로 교체한다.
- Affinity 중지는 helper에 `stop` 명령을 보내 감시만 끝내고 적용된 프로세스 마스크를 유지한다.
- 전체 복구는 helper에 `reset` 명령을 보내 접근 가능한 프로세스를 전체 논리 CPU 마스크로 설정한다.
- Electron 전용 helper는 게임 종료 시에도 백그라운드 Affinity를 자동 원복하지 않는다.
- NIC 적용 소유 상태는 helper 중지·재실행·앱 재시작에도 전달한다.
- 전체 복구는 NIC 적용 소유 상태가 있을 때만 저장된 RSS 원본을 복원한다.
- 현재 NIC가 저장된 원본과 이미 같으면 `Restart-NetAdapter`를 실행하지 않는다.
- 네트워크 카드는 패스트핑과 TCP 자동 조정이 모두 목표값일 때만 최적화됨으로 판정한다.
- 네트워크 최적화는 추가 UAC 없이 TCP 자동 조정을 먼저 복구하고 패스트핑을 조건부 적용한다.
- 관리자 여부는 현재 Windows identity의 Administrator 역할을 PowerShell로 확인한다.
- 일반 권한이면 현재 개발·배포 실행 인자를 보존해 `RunAs`로 한 번 재실행한다.
- 이후 네트워크와 Affinity helper는 `RunAs`를 반복하지 않고 승격된 앱의 관리자 토큰을 상속한다.
- 개발 실행의 최초 Electron 런처가 정상 종료되어도 Vite는 계속 실행한다.
- BrowserWindow는 즉시 표시하고 로드 실패 시 검은 화면 대신 오류 내용을 표시한다.
- NIC 상태는 30초 캐시하되 전체·수동 새로고침과 NIC 적용·복원 직후에는 강제 갱신한다.
- Affinity helper와 그 자식 PowerShell은 CPU 0~7 마스크를 상속한다.
- NIC 적용 직후 드라이버 반영 지연은 500ms 간격으로 최대 10회 재확인한다.
- 중지된 helper의 과거 NIC 오류는 현재 RSS가 목표값이면 해결된 오류로 숨긴다.
- 메모리 최적화는 별도 helper가 마비노기 실행 여부를 감지하고 기존 임계치·재발동 정책을 실행한다.
- 메모리 helper는 사용 가능 RAM, Standby RAM, 임계치와 감시 상태를 원자적 JSON으로 UI에 전달한다.
- 프레임 부스트 IPC는 Affinity와 메모리 helper를 `Promise.all`로 함께 실행·일시정지한다.
- 프레임 부스트 상태는 두 helper가 모두 실행 중일 때 실시간 부스트, 하나만 실행되면 일부 실행으로 표시한다.
- `audiodg.exe`는 사용자 요청으로 제외 목록에서 제거되어 게임 실행 중 백그라운드 CPU 범위 적용 대상이다.
- 앱 종료 시 웹 모달의 선택에 따라 Affinity 전체 복구 또는 현재 적용 유지 후 helper를 종료하며 메모리 helper도 정상 종료한다.
- Affinity 실행 여부는 상태 JSON만 읽고 NIC 상세 상태는 일반 상태 조회 경로에서만 결합한다.
- helper가 적용·복원한 NIC 상태를 상태 JSON으로 반환해 부모의 추가 PowerShell 검증을 생략한다.
- Affinity helper는 250ms 간격으로 종료 파일을 확인하며 평상시 affinity 갱신 간격은 기존 2초를 유지한다.
- 실시간 UI 동기화는 상태 JSON만 읽으며 PowerShell·NIC 조회를 실행하지 않는다.
- 렌더러가 숨겨졌거나 이전 요청이 진행 중이면 다음 실시간 요청을 건너뛴다.
- 메모리 실시간 동기화도 화면이 보이고 helper가 실행 중일 때만 동작하며 중복 요청을 방지한다.
- 메모리 helper의 실제 측정 갱신 주기는 1초이므로 UI 반영은 최대 약 1.5초다.
- 시작 창은 즉시 생성하고 최초 전체 상태 IPC만 프레임 부스트 helper 초기화를 기다린다.
- OST·파동은 앱 최초 시작에서만 재생하고 Affinity의 게임 감지 전환에서는 다시 재생하지 않는다.
- 파동 컴포넌트는 이미지 로드 전 트리거를 보류하고 해제 시 타이머, 프레임과 오디오를 정리한다.
- chicken의 `main1.png`와 `ost.mp3`를 Vite `public` 자산으로 복사해 `file://` 배포에서도 상대 경로로 읽는다.
- 로딩 파동은 최초 전체 상태 IPC가 완료될 때까지 약 2.4초 주기로 계속 생성되고 완료 후 450ms에 종료된다.
- 프레임리스 창은 렌더러의 제한된 `application:request-close` IPC를 통해 기존 종료 확인 모달을 사용한다.
- OST는 17.5초 cue에서 실제 재생을 시작하고 Canvas·볼륨은 `audio.currentTime`을 기준 시계로 사용한다.
- 시작 화면 종료 후에도 Canvas 애니메이션 루프를 배경에서 유지해 클릭 파동을 렌더링한다.
- 상태 문구 클릭은 전역 mousedown이 만든 일반 파동을 제거하고 크기 600, 두께 400, 지속 3000ms 대형 파동으로 교체한다.
- 시작 오버레이는 OST·파동 타임라인 완료와 최초 전체 상태 조회 완료를 모두 기다리는 동기화 지점이다.
- 시작 화면 전환 타이머와 오디오 종료 타이머를 분리해 마지막 파동 위에서 `실시간 부스트중` 전환이 겹친다.
- compact 홈은 시작 오버레이가 실제로 숨은 시점에만 마운트해 텍스트 전환 애니메이션이 가려지지 않게 한다.
- 상태 전환 중 이전·새 문구를 반대 방향 clip-path로 분리해 반투명 레이어 뒤로 이전 문구가 비치지 않게 한다.
- 기존 상세 대시보드는 숨기고 640×290에 맞춘 홈·설정 화면이 동일한 서비스 상태와 IPC 작업 함수를 재사용한다.
- helper 모드는 단일 인스턴스 잠금에서 제외하고 일반 앱만 잠금을 획득한다.
- 비관리자 런처는 UAC 재실행 직전에 잠금을 해제하고 승격된 앱이 다시 획득한다.
- `second-instance` 이벤트는 창이 없으면 요청을 보류하고, 최소화 상태면 복원한 뒤 임시 최상단·`moveTop()`으로 전면 배치한다.

## Known Issues
- `runtime-state.json`을 직접 덮어써 동시 읽기 시 일시적으로 불완전한 JSON이 노출될 수 있다.
- 복구 실패 여부와 관계없이 상태 파일을 삭제하는 기존 동작이 남아 있다.
- 실행 중인 기존 인스턴스와 동시에 드라이런했을 때 상태 파일 파싱 오류가 재현됐다.
- 네트워크 모듈 외 기능에는 자동화된 단위·통합 테스트와 CI가 없다.
- 저지연 모드 ID는 NVIDIA 공개 NVAPI가 아니므로 드라이버 변경 시 호환성이 깨질 수 있다.
- 비공개 저지연 값 적용·검증은 NVIDIA Profile Inspector 호환 내부 setter/getter ABI에 의존한다.
- 인터페이스 재시작 중 네트워크 연결이 잠시 끊기며 실행에는 관리자 권한이 필요하다.
- Electron 창과 UAC 승격 보조 프로세스는 자동화된 통합 테스트 없이 빌드·구문 검사만 완료했다.
- 현재 TCP 자동 조정은 `Experimental`이며 관리자 권한 적용 전까지 비최적화로 남아 있다.
- NIC RSS 적용·복원은 관리자 권한과 인터페이스 재시작이 필요하다.
- Affinity 장기 실행 helper의 실제 UAC 시작·종료·비정상 종료 복구는 아직 수동 검증하지 않았다.
- 기존 CLI nogirem과 Electron Affinity helper를 동시에 실행하면 서로의 적용 상태를 소유하지 못하므로 함께 실행하지 않아야 한다.
- Electron 메인과 sandbox 렌더러를 포함한 앱 전체가 관리자 권한으로 실행되므로 preload IPC 허용 범위를 계속 제한해야 한다.
- 17:53에 시작된 수정 전 관리자 Electron PID 54644가 20:19에도 남아 있으며, 20시 이후 프로세스는 종료돼 단일 인스턴스 재실행이 계속 구버전 창만 포커스한다.
- 개발 실행은 승격 앱 종료를 추적하지 않으므로 Vite 터미널은 별도로 `Ctrl+C` 종료해야 한다.
- 메모리 helper의 실제 게임 감지와 압박 조건 정리는 자동화된 통합 테스트 없이 상태 조회·빌드로만 검증했다.
- NIC RSS를 실제 변경·복원하는 최초 토글은 네트워크 인터페이스 재시작 때문에 빠르게 완료할 수 없다.
- 현재 승격된 Electron PID 52832는 일반 권한 셸에서 종료 권한이 거부되어 사용자가 직접 닫아야 한다.
- 작업 관리자 강제 종료나 프로세스 강제 제거는 웹 모달과 정상 helper 중지를 우회한다.
- `audiodg.exe`를 CPU 0~7로 제한하면 오디오 드롭·지연이 발생할 가능성이 있다.
- 고정 640×290 창에서는 기존 대시보드 전체 내용이 세로 스크롤로 표시된다.
- 시작 음악은 Electron의 미디어 자동재생 정책이나 오디오 장치 상태에 따라 재생이 거부될 수 있다.
- 프레임리스 창에는 시스템 최소화 버튼이 없으며 현재 커스텀 UI는 닫기만 제공한다.
