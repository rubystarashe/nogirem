# 업데이트 전환 핫픽스 요구사항

- run_id: `20260929-update-hotfix`
- goal: Rust 0.4.1 대체 산출물과 Electron 0.3.18 전환본으로 업데이트·제거 실패 경로 복구

## 요구사항

- REQ-HOTFIX-01: Electron 0.3.17 사용자가 0.3.18 전환본을 업데이트로 확인할 수 있어야 한다.
- REQ-HOTFIX-02: 0.3.18은 Rust 전환 가능 상태·진행률·실패 원인을 기존 업데이트 UI에 표시하고 사용자가 재시도할 수 있어야 한다.
- REQ-HOTFIX-03: Rust 버전은 올리지 않고 수정된 0.4.1 설치형·포터블 산출물과 서명 매니페스트로 기존 릴리스를 대체해야 한다.
- REQ-HOTFIX-04: 설치·제거 시 정상 종료 요청이 고착되면 설치 폴더 내부 프로세스만 제한적으로 종료해 진행할 수 있어야 한다.
- REQ-HOTFIX-05: 앱 종료 중 진행 중인 Rust 업데이트 다운로드를 취소해야 한다.

## 범위 제외

- Rust 0.4.2 버전 생성
- 사용자 설정·녹화 데이터 삭제
- 설치 폴더 밖 프로세스 강제 종료

## 수용 기준

- 0.3.17용 Electron 업데이터가 공개 릴리스에서 0.3.18을 선택한다.
- 0.3.18 전환 helper 상태가 UI 상태로 전달되고 오류 후 다시 실행할 수 있다.
- Rust·Node 테스트와 0.4.1 실서명 패키징, 0.3.18 bridge 패키징이 통과한다.
- 최종 v0.4.1 릴리스 자산의 해시·서명·라우팅을 공개 URL에서 검증한다.
