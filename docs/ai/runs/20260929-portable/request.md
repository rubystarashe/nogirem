# 포터블 배포 요구사항

- run_id: `20260929-portable`
- coordinator: `cursor-92251f36`

## 요구사항

- REQ-PORT-01: 설치형과 함께 배포할 Windows x64 포터블 ZIP을 생성한다.
- REQ-PORT-02: 포터블 앱도 서명된 전용 매니페스트로 업데이트를 확인하고, 종료 후 파일을 교체하며 실패 시 이전 파일로 복구한다.
- REQ-PORT-03: 포터블 앱도 관리자 권한 요청과 시스템 WebView2 의존성을 유지한다.
- REQ-PORT-04: 설치형과 포터블은 `%APPDATA%\마비노기 렘 부스터` 설정을 공유한다.
- REQ-PORT-05: 녹화 청크 저장 드라이브 선택 기능과 해당 설정 공유를 유지한다.
- REQ-PORT-06: 앱 폴더가 이동되면 기존 시작 프로그램 복구 로직으로 현재 실행 경로를 다시 등록한다.

## 제외 범위

- WebView2 고정 버전 런타임을 ZIP에 포함하지 않는다.
- 시스템 최적화 설정을 포터블 폴더에 격리하거나 종료 시 자동 복원하지 않는다.
- 릴리스 게시, 원격 업로드, 배포는 수행하지 않는다.
